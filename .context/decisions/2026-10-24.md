## 2026-10-24

- **Image renamed `opencode-sandbox` -> `agent-container`; volumes renamed to `agent-container-history` /
  `agent-container-claude-config`.** Docker can't rename volumes, so `run.sh`'s `migrate_volume` copies each old
  volume into the new name (via the just-built image, `--entrypoint cp`, as root to keep ownership) only when the
  new one doesn't exist yet. Old volumes are deliberately left in place for the user to remove by hand. A failed
  copy removes the half-filled new volume so the next run retries. Known gap: an interrupted (Ctrl-C) copy can
  leave a partial new volume that is then treated as migrated — delete it and rerun.
- Not renamed: the GitHub repo / GHCR image (`ghcr.io/jrstarke/opencode-container`, from `github.repository`).
- **Playwright Chromium system deps baked in at build time** (`npx playwright@${PLAYWRIGHT_VERSION} install-deps chromium`,
  pinned 1.64.1 — native debian13 arm64/x64 list, verified in playwright-core source). Runs as root (apt) with
  appuser's asdf node on PATH directly (root has no asdf shims). Only deps, not the browser: agents run
  `npx playwright install chromium` themselves; downloads come from cdn.playwright.dev /
  playwright.download.prss.microsoft.com, added to allowed-domains at the user's request.
- **One published port per run, `PUBLISH_PORT`.** `run.sh` picks a random free host port in the IANA ephemeral range
  (49152-65535; `49152 + RANDOM % 16384` covers it exactly), checks it's free via bash `/dev/tcp` (no lsof/ss, works on
  macOS + Linux), publishes it as `-p 127.0.0.1:P:P` — loopback-only so it isn't exposed to the LAN, and same number on
  both sides so in-container URLs work from the host. Name chosen to match Docker's `--publish` (EXPOSE_PORT would be
  confused with the Dockerfile directive, EPHEMERAL_PORT describes origin not purpose). Host can pin it by setting
  PUBLISH_PORT. Agents told (AGENTS.md.container) to bind 0.0.0.0, not 127.0.0.1. Known: check-then-bind race —
  if another process grabs the port in between, docker run fails "port is already allocated"; just rerun.
